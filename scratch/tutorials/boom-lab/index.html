Scratch tutorial for kids (9+) · 8 steps · basic blocks only

Boom Lab

Welcome to the test range! Build eight explosion effects, from a simple flip-book pop to a mega blast with a flash, a shockwave, sparks, smoke, a ground shake and bouncing debris. Pick an effect in the toolbar and click the sky to try it.

Every step is a lab you can play with, and every step has a file you can download if you get stuck. You need the Scratch editor: scratch.mit.edu/projects/editor.

Start here: the starter project has the sky, the ground, the explosion costumes, the flash and the toolbar. No code yet.

1

Pop

Big idea: a flip-bookThe Boom sprite stays hidden and waits for a click in the sky. Then it goes to the mouse-pointer and runs boom, which uses make 1 pop: set role to pop and make a clone. The clone shows itself and switches to the next costume every 0.05 seconds: five pictures, one after the other, like a flip-book.

Make: effect, and role, vx, vy and spin for the Boom only, and name for the Button only. The custom blocks make (n) (kind) and boom, both with run without screen refresh.

Boom new
when flag clicked
hide
forever
  wait until <<mouse down?> and <(mouse y) > (-135)>>
  go to (mouse-pointer v)
  boom :: custom
  wait until <not <mouse down?>>
end
Boom new
define make (n :: custom) (kind :: custom)
set [role v] to (kind :: custom)
repeat (n :: custom)
  create clone of (myself v)
end
Boom new
define boom
if <(effect) = [pop]> then
  make (1) [pop] :: custom
end
Boom new
when I start as a clone
if <(role) = [pop]> then
  switch costume to (pop1 v)
  show
  repeat (4)
    wait (0.05) seconds
    next costume
  end
  wait (0.05) seconds
  delete this clone
end
Button new
when flag clicked
switch costume to (bar v)
go to x: (0) y: (-160)
show
set [effect v] to [pop]
set [name v] to [pop]
switch costume to (pop v)
go to x: (-203) y: (-160)
create clone of (myself v)
set [name v] to []
switch costume to (bar v)
go to x: (0) y: (-160)
Button new
when I start as a clone
go to [front v] layer
forever
  if <(effect) = (name)> then
    set size to (112) %
    set [brightness v] effect to (0)
  else
    set size to (92) %
    set [brightness v] effect to (-30)
  end
end
Button new
when this sprite clicked
if <not <(name) = []>> then
  set [effect v] to (name)
end
  • The Button sprite is the dark toolbar; it makes a clone for each button. Click a button to pick its effect.
  • Click fast: every click makes its own clone, so pops can overlap.

Fireball

Big idea: grow and fadeYou don't always need lots of costumes. A fireball is one soft, round costume: start small, then change size by 12 and change ghost effect by 7, fourteen times. It swells up and fades away.

Ring

Big idea: clones copy your directionmake (16) (spark) now turns 360 ÷ 16 degrees before each clone. A clone starts with the direction its parent had at that moment, so the 16 sparks point all the way round. Each one just moves forward and shrinks.

Make: nothing new: make changes.

Boom changed
define make (n :: custom) (kind :: custom)
set [role v] to (kind :: custom)
repeat (n :: custom)
  turn right ((360) / (n :: custom)) degrees
  create clone of (myself v)
end

Sparks

Big idea: gravityEmbers fly out in an arc, like real sparks. Each one picks a random vx (sideways) and vy (up). Every frame it moves by vx and vy, and then vy goes down by 0.6. That is gravity: the ember slows down, stops and falls.

Make: nothing new: vx and vy are already there.

Boom changed
define boom
if <(effect) = [pop]> then
  make (1) [pop] :: custom
else
  if <(effect) = [fireball]> then
    make (1) [fireball] :: custom
  else
    if <(effect) = [ring]> then
      make (16) [spark] :: custom
    else
      if <(effect) = [sparks]> then
        make (20) [ember] :: custom
      end
    end
  end
end
Boom new
when I start as a clone
if <(role) = [ember]> then
  switch costume to (ember v)
  set [vx v] to ((0.1) * (pick random (-50) to (50)))
  set [vy v] to (pick random (3) to (10))
  show
  repeat (35)
    change x by (vx)
    change y by (vy)
    change [vy v] by (-0.6)
    change [ghost v] effect by (2.5)
  end
  delete this clone
end

Smoke

Big idea: slow and randomSmoke is soft because nothing about it is the same: each puff has a random size, place, start time and drift. Then it slowly rises, grows and fades. Slow and random looks soft; fast and even looks hard.

Make: nothing new.

Blast

Big idea: flash and shockwaveBig explosions are made of small ones. Blast broadcasts flash, and the Flash sprite (the whole screen, warm white) shows and fades in a few frames. At the same time a shockwave ring grows very fast, with a fireball and a ring of sparks inside.

Make: nothing new: the Flash sprite is in the starter.

Quake

Big idea: shake, less and lessQuake broadcasts shake. The Land sprite jumps to a random spot near home, 12 times, and each time a little less far (jolt goes down by 1). Then it goes home. The ground is wider than the stage, so you never see its edges.

Make: jolt for the Land only.

Land new
when flag clicked
go to x: (0) y: (-95)
Land new
when I receive [shake v]
set [jolt v] to (12)
repeat (12)
  go to x: (pick random ((-1) * (jolt)) to (jolt)) y: ((-95) + (pick random ((-1) * (jolt)) to (jolt)))
  change [jolt v] by (-1)
end
go to x: (0) y: (-95)

Mega

Big idea: bounce and mix it allDebris flies, spins and falls like the embers, but when it reaches the ground it bounces: vy turns round and halves, and it slows down sideways. Mega sets off everything at once: flash, shake, shockwave, fireball, ring, sparks, smoke and debris.

Make: nothing new.

Boom changed
define boom
if <(effect) = [pop]> then
  make (1) [pop] :: custom
else
  if <(effect) = [fireball]> then
    make (1) [fireball] :: custom
  else
    if <(effect) = [ring]> then
      make (16) [spark] :: custom
    else
      if <(effect) = [sparks]> then
        make (20) [ember] :: custom
      else
        if <(effect) = [smoke]> then
          make (6) [smoke] :: custom
        else
          if <(effect) = [blast]> then
            broadcast (flash v)
            make (1) [shock] :: custom
            make (1) [fireball] :: custom
            make (12) [spark] :: custom
          else
            if <(effect) = [quake]> then
              broadcast (shake v)
              make (1) [shock] :: custom
              make (5) [smoke] :: custom
              make (6) [chunk] :: custom
            else
              if <(effect) = [mega]> then
                broadcast (flash v)
                broadcast (shake v)
                make (1) [shock] :: custom
                make (1) [fireball] :: custom
                make (16) [spark] :: custom
                make (16) [ember] :: custom
                make (6) [smoke] :: custom
                make (8) [chunk] :: custom
              end
            end
          end
        end
      end
    end
  end
end
Boom new
when I start as a clone
if <(role) = [chunk]> then
  switch costume to (join [chunk] (pick random (1) to (2)))
  set [vx v] to ((0.1) * (pick random (-60) to (60)))
  set [vy v] to (pick random (5) to (11))
  set [spin v] to (pick random (-25) to (25))
  show
  repeat (70)
    change x by (vx)
    change y by (vy)
    change [vy v] by (-0.6)
    turn right (spin) degrees
    if <<(y position) < (-100)> and <(vy) < (0)>> then
      set y to (-100)
      set [vy v] to ((-0.5) * (vy))
      set [vx v] to ((0.7) * (vx))
      set [spin v] to ((0.5) * (spin))
    end
  end
  repeat (10)
    change [ghost v] effect by (10)
  end
  delete this clone
end

Make it your own

  • A colour explosion: change the color effect by a random amount for each spark.
  • A slow-motion button: one variable that every clone uses as its speed.
  • Your own recipe: a ninth button with the pieces you like best.
  • Put an explosion in one of your games: when a ship is hit, go there and boom.
