# scratch-pseudo

Converts a Scratch 3 `project.json` into readable pseudocode.

## Usage

```
node --experimental-strip-types --no-warnings pseudo.ts <project.json>
```

Requires Node 22 or later.

## Example

`examples/` contains "Christmas Tree -Pen-" by poporon (Scratch project 183618719) and its generated pseudocode.
