Scratch tutorial for kids (9+) · 8 steps · basic blocks only

Slime Siege

Slimes are zigzagging across the meadow towards your keep! Drag cannons anywhere you like: fixed cannons shoot the way you point them, and seeker cannons aim at the slime in front. Destroyed slimes give coins for more cannons, repairs and upgrades: faster shooting, stronger bolts, bolts that fly through, and sturdier cannons.

Every step is a game you can play, and every step has a file you can download if you get stuck. You need the Scratch editor: scratch.mit.edu/projects/editor.

Start here: the starter project has the keep, the slimes, the cannons, the target, the tools and the meadow. No code yet.

Slimes

Big idea: point towards, then wiggleThe Slime sprite hides and, every few seconds, makes a clone at a random place on the right edge. Each clone heads for the keep: point towards Keep, then turn a little left or right, then move. The turn comes from a wave, 40 × sin(timer × 200), so the slimes zigzag.

Make: speed and wiggle for the Slime only. The starter already has the Keep, Slime, Tower, Target, Tool and Ring sprites and the meadow.

Slime new
when flag clicked
hide
forever
  wait (pick random (2) to (3.5)) seconds
  go to x: (228) y: (pick random (-105) to (165))
  create clone of (myself v)
end
Slime new
when I start as a clone
set [health v] to (3)
set [ouch v] to (0)
set [speed v] to (0.7)
set [wiggle v] to (pick random (0) to (360))
switch costume to (green v)
show
repeat until <touching (Keep v)?>
  point towards (Keep v)
  turn right ((40) * ([sin v] of ((wiggle) + ((timer) * (200))))) degrees
  move (speed) steps
end
delete this clone
  • Each slime starts its wave at a different point (wiggle is random), so they don't all zigzag together.
  • Try a bigger number than 40: how wild can they zigzag?

Cannons

Big idea: drag anywhere, click to turnClick the cannon in the shop and a new one appears under your mouse. Its clone script says repeat until not mouse down: go to mouse-pointer: it follows you until you let go, wherever you like on the meadow. Click a placed cannon and it turns 45°: this is the fixed cannon, and you decide where it points.

Make: the variable coins, and role, kind, price, hp, maxhp, delay, power, pierce and locked for this sprite only.

end

  • A fixed cannon costs 15 coins.

Shooting

Big idea: bolts are clones of their cannonEvery 0.7 seconds the cannon becomes a bolt for a moment and makes a clone of itself, then turns back into a cannon. The clone starts where the cannon is and points the same way, so it flies off in the cannon's direction.

Make: nothing new.

Tower changed
when I start as a clone
if <(role) = [new]> then
  repeat until <(role) = [tower]>
    wait (0.05) seconds
  end
  forever
    wait (delay) seconds
    if <(locked) = (1)> then
      set [role v] to [bolt]
      if <(power) = (2)> then
        switch costume to (power v)
      else
        switch costume to (bolt v)
      end
      create clone of (myself v)
      set [role v] to [tower]
      switch costume to (kind)
    end
  end
end
  • A fixed cannon always shoots, whether there is a slime or not: point it where the slimes will come.
  • The bolt moves 24 steps first, so it starts at the end of the barrel.

The seeker

Big idea: who is in front?The seeker cannon (35 coins) aims by itself, at the slime closest to the keep. Every frame, each slime checks: is my distance to Keep smaller than nextD? If so it writes its distance and position there. The hidden Target sprite then goes to that position and sets nextD back to 9999 for the next frame. A seeker just says point towards Target, and shoots when Target is within range.

Make: the sprite Target is already there. Make the variables nextD, nextX, nextY and front.

Upgrades

Big idea: a tool, then a cannonFour more tools: Speed (shoots twice as often), Damage (red bolts that take 2 health), Pierce (bolts fly through slimes) and Strength (double health). Pick a tool, then click a cannon: only that cannon gets the upgrade.

Make: nothing new: the upgrades change the cannon's own variables.

Waves

Big idea: one number makes it harderAfter every 8 slimes the wave goes up: more health, faster, new colours. From wave 3 they also come from the top and the bottom, and every fifth wave starts with a big boss slime.

Make: the variable wave.

Slime changed
when flag clicked
hide
set [wave v] to (1)
set [spawned v] to (0)
forever
  wait ((((0.6) + ((3) - ((0.25) * (wave)))) + ([abs v] of ((0.6) - ((3) - ((0.25) * (wave)))))) / (2)) seconds
  go to x: (228) y: (pick random (-105) to (165))
  if <(wave) > (2)> then
    if <(pick random (1) to (4)) = (1)> then
      go to x: (pick random (-60) to (220)) y: (172)
    else
      if <(pick random (1) to (4)) = (1)> then
        go to x: (pick random (-60) to (220)) y: (-110)
      end
    end
  end
  change [spawned v] by (1)
  if <((spawned) mod (8)) = (0)> then
    change [wave v] by (1)
  end
  create clone of (myself v)
end

Make it your own

  • A Range upgrade for the seeker: a bigger distance before it shoots.
  • A wall: a cheap cannon that does not shoot but has lots of health, to slow the slimes down.
  • Selling: a Sell tool that removes a cannon and gives back half its price.
  • Fast slimes that are weak, and slow slimes that are strong.
