Scratch tutorial for kids (8+) · 5 steps · basic blocks only

Splat Patrol

Sneaky raccoon bandits are hiding in the houses, ready to throw water balloons. Windows pop open: splat the raccoons before they splat you, but don't splash the granny or the kid! Round after round the houses change, and the raccoons get quicker.

Every step is a game you can play, and every step has a file you can download if you get stuck. You need the Scratch editor: scratch.mit.edu/projects/editor.

Start here: the starter project has the window with all its costumes, the crosshair, the goo and three houses. No code yet.

Open and close

Big idea: costumes tell the storyThe Window sprite has a costume for every moment: shut, open, and one for everybody who can look out. A forever loop waits a random time, switches to the raccoon, waits, and shuts again. That is already a little play!

Make: nothing new yet. The starter has the Window (with all its costumes), the Crosshair, the Goo and three house backdrops.

Window new
when flag clicked
go to x: (-110) y: (20)
switch costume to (shut v)
show
forever
  wait (pick random (1) to (3)) seconds
  switch costume to (raccoon v)
  wait (1.5) seconds
  switch costume to (shut v)
end
Crosshair new
when flag clicked
go to [front v] layer
forever
  go to (mouse-pointer v)
end
  • wait (pick random 1 to 3) seconds makes the raccoon hard to predict. Try 0.2 to 0.5 for a very busy raccoon.
  • Look at the Window's costumes: the order matters later. 1 is shut, 2 is open, 3 to 5 are the raccoon, the granny and the kid, then their splashed versions.

Splat!

Big idea: the crosshair gets the clickThe crosshair follows the mouse, so it is always on top of whatever you click. That's why the crosshair gets the click, not the window. It broadcasts splat, and the window checks: is somebody looking out, and am I touching the mouse-pointer? Then they're hit.

Make: the variable score (for all sprites); on the Window who, hit and close for this sprite only; the message splat.

Window changed
when flag clicked
go to x: (-110) y: (20)
switch costume to (shut v)
show
forever
  wait (pick random (1) to (3)) seconds
  switch costume to (open v)
  wait (0.15) seconds
  if <(pick random (1) to (100)) < (60)> then
    set [who v] to [raccoon]
  else
    if <(pick random (1) to (2)) = (1)> then
      set [who v] to [granny]
    else
      set [who v] to [kid]
    end
  end
  switch costume to (who)
  set [hit v] to (0)
  set [close v] to ((timer) + (1.5))
  repeat until <<(hit) = (1)> or <(timer) > (close)>>
    wait (0.02) seconds
  end
  if <(hit) = (1)> then
    wait (0.6) seconds
  end
  switch costume to (shut v)
end
Window new
when I receive [splat v]
if <<<(hit) = (0)> and <touching (mouse-pointer v)?>> and <<(costume [number v]) > (2)> and <(costume [number v]) < (6)>>> then
  set [hit v] to (1)
  switch costume to (join (who) [ splat])
  if <(who) = [raccoon]> then
    change [score v] by (1)
  else
    change [score v] by (-1)
  end
end
Crosshair changed
when flag clicked
set [score v] to (0)
go to [front v] layer
forever
  go to (mouse-pointer v)
end
Crosshair new
when this sprite clicked
broadcast (splat v)
  • who is picked at random: 60 out of 100 times a raccoon, otherwise the granny or the kid. The costume has the same name as who, so switch costume to (who) just works.
  • close is timer + 1.5: the window stays open until the timer passes it, or until hit becomes 1.
  • The splashed costume is join (who) [ splat], like "raccoon splat".
  • There is no wait in the splat script on purpose: a second click would start that script again in the middle of its wait.

A whole house

Big idea: one script, many windowsThe Window sprite now hides and builds the house: it goes to each window spot and creates a clone of myself. The forever loop moves to when I start as a clone, so every window runs it on its own.

Make: on the Window isClone for this sprite only.

Window changed
when flag clicked
hide
set [isClone v] to (0)
go to x: (-110) y: (20)
create clone of (myself v)
go to x: (110) y: (20)
create clone of (myself v)
go to x: (0) y: (-88)
create clone of (myself v)
Window new
when I start as a clone
set [isClone v] to (1)
switch costume to (shut v)
show
forever
  wait (pick random (1) to (3)) seconds
  switch costume to (open v)
  wait (0.15) seconds
  if <(pick random (1) to (100)) < (60)> then
    set [who v] to [raccoon]
  else
    if <(pick random (1) to (2)) = (1)> then
      set [who v] to [granny]
    else
      set [who v] to [kid]
    end
  end
  switch costume to (who)
  set [hit v] to (0)
  set [close v] to ((timer) + (1.5))
  repeat until <<(hit) = (1)> or <(timer) > (close)>>
    wait (0.02) seconds
  end
  if <(hit) = (1)> then
    wait (0.6) seconds
  end
  switch costume to (shut v)
end
  • Every clone has its own who, hit and close, because they are for this sprite only. That's why three windows can each have a different visitor.
  • The splat script didn't change at all: only the window under the mouse-pointer answers.

Raccoons splat back

Big idea: a timer you can lose toIf a raccoon is still there when its time is up, it throws its water balloon at you: green goo on the screen, and one life gone. Splashing a villager costs a life too. Three lives, then it's game over.

Make: the variable lives; the messages splatted and oops; a script for the Goo sprite (it's in the starter).

Window changed
when I start as a clone
set [isClone v] to (1)
switch costume to (shut v)
show
forever
  wait (pick random (1) to (3)) seconds
  switch costume to (open v)
  wait (0.15) seconds
  if <(pick random (1) to (100)) < (60)> then
    set [who v] to [raccoon]
  else
    if <(pick random (1) to (2)) = (1)> then
      set [who v] to [granny]
    else
      set [who v] to [kid]
    end
  end
  switch costume to (who)
  set [hit v] to (0)
  set [close v] to ((timer) + (1.5))
  repeat until <<(hit) = (1)> or <(timer) > (close)>>
    wait (0.02) seconds
  end
  if <<(hit) = (0)> and <(who) = [raccoon]>> then
    broadcast (splatted v)
  end
  if <(hit) = (1)> then
    wait (0.6) seconds
  end
  switch costume to (shut v)
end
Window changed
when I receive [splat v]
if <<<(hit) = (0)> and <touching (mouse-pointer v)?>> and <<(costume [number v]) > (2)> and <(costume [number v]) < (6)>>> then
  set [hit v] to (1)
  switch costume to (join (who) [ splat])
  if <(who) = [raccoon]> then
    change [score v] by (1)
  else
    broadcast (oops v)
  end
end
Crosshair changed
when flag clicked
set [score v] to (0)
set [lives v] to (3)
say []
go to [front v] layer
forever
  go to (mouse-pointer v)
end
Crosshair new
when I receive [splatted v]
change [lives v] by (-1)
if <(lives) = (0)> then
  say [Game over! Click the green flag.] for (2) seconds
  stop [all v]
end
Crosshair new
when I receive [oops v]
change [lives v] by (-1)
if <(lives) = (0)> then
  say [Game over! Click the green flag.] for (2) seconds
  stop [all v]
end
say [Oops! Sorry!] for (1) seconds
Goo new
when flag clicked
hide
Goo new
when I receive [splatted v]
show
go to [front v] layer
wait (0.4) seconds
hide
  • The window only checks one thing after its loop: hit is 0 and who is raccoon? Then broadcast splatted.
  • The Goo shows for 0.4 seconds. The Crosshair counts the lives.
  • say … for 2 seconds comes before stop all: stop all also clears speech bubbles.

Round after round

Big idea: two numbers make it harderEvery 15 seconds a new round starts, and the houses take turns: the cottage, the shop, the town house, and again. Each round showTime gets shorter and badChance gets bigger. Those two numbers are the whole difficulty.

Make: variables round, house, showTime and badChance; messages clear and build.

Stage new
when flag clicked
set [round v] to (1)
forever
  set [showTime v] to ((2.2) - ((round) * (0.2)))
  if <(showTime) < (0.7)> then
    set [showTime v] to (0.7)
  end
  set [badChance v] to ((50) + ((round) * (8)))
  if <(badChance) > (85)> then
    set [badChance v] to (85)
  end
  set [house v] to ((((round) - (1)) mod (3)) + (1))
  switch backdrop to (house)
  broadcast (clear v) and wait
  broadcast (build v) and wait
  wait (15) seconds
  change [round v] by (1)
end
Window changed
when flag clicked
hide
set [isClone v] to (0)
Window new
when I receive [build v]
if <(isClone) = (0)> then
  if <(house) = (1)> then
    go to x: (-110) y: (20)
    create clone of (myself v)
    go to x: (110) y: (20)
    create clone of (myself v)
    go to x: (0) y: (-88)
    create clone of (myself v)
  end
  if <(house) = (2)> then
    go to x: (-165) y: (40)
    create clone of (myself v)
    go to x: (-55) y: (40)
    create clone of (myself v)
    go to x: (55) y: (40)
    create clone of (myself v)
    go to x: (165) y: (40)
    create clone of (myself v)
  end
  if <(house) = (3)> then
    go to x: (-110) y: (100)
    create clone of (myself v)
    go to x: (0) y: (100)
    create clone of (myself v)
    go to x: (110) y: (100)
    create clone of (myself v)
    go to x: (-110) y: (-20)
    create clone of (myself v)
    go to x: (0) y: (-20)
    create clone of (myself v)
    go to x: (110) y: (-20)
    create clone of (myself v)
  end
end
Window new
when I receive [clear v]
if <(isClone) = (1)> then
  delete this clone
end
Window changed
when I start as a clone
set [isClone v] to (1)
switch costume to (shut v)
show
forever
  wait (pick random (1) to (3)) seconds
  switch costume to (open v)
  wait (0.15) seconds
  if <(pick random (1) to (100)) < (badChance)> then
    set [who v] to [raccoon]
  else
    if <(pick random (1) to (2)) = (1)> then
      set [who v] to [granny]
    else
      set [who v] to [kid]
    end
  end
  switch costume to (who)
  set [hit v] to (0)
  set [close v] to ((timer) + (showTime))
  repeat until <<(hit) = (1)> or <(timer) > (close)>>
    wait (0.02) seconds
  end
  if <<(hit) = (0)> and <(who) = [raccoon]>> then
    broadcast (splatted v)
  end
  if <(hit) = (1)> then
    wait (0.6) seconds
  end
  switch costume to (shut v)
end
  • showTime is 2.2 − round × 0.2, but never below 0.7 seconds. badChance is 50 + round × 8, but never above 85.
  • house is (round − 1) mod 3 + 1: 1, 2, 3, 1, 2, 3 … The backdrops are in the same order, so switch backdrop to (house) picks the right house.
  • clear deletes the old clones, build makes the new ones. Each house has its own list of go to and create clone.
  • This is the whole game! Try your own house: draw a backdrop and add a new if house = 4.

Make it your own

  • A golden raccoon that is worth 5 points: add a costume, and a who that is picked once in 20 times.
  • A sound for every splat, and a different one for "Oops!".
  • Your own house: a new backdrop and an if house = 4 with its window spots. Remember to change mod 3 to mod 4.
  • Make it fairer for little brothers and sisters: start showTime at 3 seconds.
